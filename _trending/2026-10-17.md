## **2. 🚨 緊急セキュリティ情報**

### **Axios - プロトタイプ汚染によるJSONレスポンス改ざんおよびデータ漏洩**

- **🔰 ひとことで言うと**: 通信に使うプログラムの裏をかいて、本来の権限以上の操作をされたり、大事なデータを盗み見られたりする恐れがあります。
- **内容**: Axiosのデフォルト設定にある `transformResponse` において、`JSON.parse` の第2引数である `parseReviver` の扱いに起因するプロトタイプ汚染の脆弱性（GHSA-3w6x-2g7m-8v23）が公開されました（CVE-2026-42044）。攻撃者が `Object.prototype.parseReviver` を汚染できた場合、アプリケーションが受け取るJSONレスポンスの特定の値をこっそり改ざん（例: `isAdmin: false` を `true` にする等）したり、トークンなどの情報を抽出することが可能です。アプリケーションをクラッシュさせずに不正な権限昇格やデータ漏洩を引き起こせるため、非常に深刻です。
- **リスク度**: 中 (CVSS:3.1/AV:N/AC:H/PR:N/UI:N/S:U/C:L/I:H/A:N)
- **📊 影響の大きさ**:
  - **影響を受ける人**: Axiosのバージョン `1.0.0` から `1.15.2` 以下を利用して、外部のAPIとJSON形式で通信している全てのユーザー。
  - **悪用の容易さ**: プロトタイプ汚染自体を引き起こす別の入り口（他のライブラリの脆弱性など）が必要ですが、一度成立すればAxiosのすべての通信に対して目に見えない形で攻撃が可能です。
- **対象バージョン/環境**: `axios >= 1.0.0, <= 1.15.2`
- **対策・ステータス**: 最新のパッチバージョンにアップデートしてください。根本的な対処として、`mergeConfig.js` 等で `Object.create(null)` を使用し、プロトタイプチェーンの参照を遮断する修正が行われています。
- **🛡️ まずやるべきこと**: ご自身のプロジェクトの `package.json` で使用しているAxiosのバージョンを確認し、可能であれば最新版へアップデートしてください。
- **詳細リンク**: [GHSA-3w6x-2g7m-8v23](https://github.com/axios/axios/security/advisories/GHSA-3w6x-2g7m-8v23)

### **LangChain-Community - プロンプトインジェクション経由のSQLインジェクション**

- **🔰 ひとことで言うと**: AIに特殊な命令を出すことで、裏側のデータベースを勝手に書き換えられたり、データを盗み出されたりする危険性があります。
- **内容**: LangChainエコシステムの `langchain-community` パッケージにおいて、`GraphCypherQAChain` クラスにSQLインジェクションの脆弱性（CVE-2024-8309 / PYSEC-2024-115）が発見されました。この脆弱性は、ユーザーからの入力を適切にサニタイズ（無害化）せずにプロンプトに組み込んでいることに起因します。攻撃者が巧みに作成したプロンプト（プロンプトインジェクション）を送信することで、生成されたクエリに悪意のあるSQL/Cypher文が混入し、意図しないデータの削除（DoS）やマルチテナント環境におけるデータ漏洩が発生する可能性があります。
- **リスク度**: 高 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H)
- **📊 影響の大きさ**:
  - **影響を受ける人**: `langchain-community` バージョン `0.2.0` から `0.2.19` （`0.3.0` 未満）を使用し、データベースと連動したAIアプリケーションを構築している開発者および運用者。
  - **悪用の容易さ**: チャットUIなどの入力フォームからAIに話しかけるだけで攻撃が成立する可能性があるため、悪用は非常に容易です。
- **対象バージョン/環境**: `langchain-community >= 0.2.0, < 0.3.0`
- **対策・ステータス**: `langchain-community` を `0.3.0` 以上にアップデートしてください。また、AIに直接データベースクエリを生成・実行させるアーキテクチャを見直し、権限を最小限に絞った読み取り専用ユーザーを使用するなどの「多層防御」を適用してください。
- **🛡️ まずやるべきこと**: アプリケーションを最新版に更新し、AIがデータベースにアクセスする際の権限が「読み取り専用」になっているかを確認してください。
- **詳細リンク**: [GHSA-45pg-36p6-83v9](https://github.com/advisories/GHSA-45pg-36p6-83v9)

### **Picklescan - 非標準拡張子によるセキュリティチェックの回避**

- **🔰 ひとことで言うと**: AIのファイルを安全かチェックするツールが、ファイルの名前を少し変えるだけで騙されてしまい、危険なファイルを見逃す問題です。
- **内容**: 機械学習モデルのシリアライズ形式（Pickle）に潜む悪意のあるコードを検出するセキュリティツール「Picklescan」において、スキャンバイパスの脆弱性（CVE-2025-1889 / PYSEC-2025-19）が公開されました。このツールは標準的な拡張子を持つファイルのみをスキャン対象として考慮していたため、攻撃者が悪意のあるPickleファイルを非標準の拡張子でAIモデルパッケージに含めた場合、Picklescanのセキュリティチェックを素通りしてしまう問題があります。
- **リスク度**: 高 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H)
- **📊 影響の大きさ**:
  - **影響を受ける人**: モデルの安全性を「Picklescan バージョン 0.0.21 以下」で確認しているデータサイエンティストやエンジニア。
  - **悪用の容易さ**: 攻撃者はファイルの拡張子を変更してパッケージ化するだけでよく、極めて簡単にスキャンを回避できます。
- **対象バージョン/環境**: `picklescan <= 0.0.21`
- **対策・ステータス**: 修正されたバージョン `0.0.22` にアップデートしてください。
- **🛡️ まずやるべきこと**: モデルをチェックするツールのバージョンを確認し、アップデートを実施してください。出所の怪しいAIモデルは安易にロードしないでください。
- **詳細リンク**: [GHSA-769v-p64c-89pr](https://github.com/advisories/GHSA-769v-p64c-89pr)

## **4. 🔥 注目のトレンドツール**

### **PS5LM**

- **🔰 ひとことで言うと**: 改造したPlayStation 5のパワーを使って、パソコンがなくても高性能なAIを家庭で動かせるようにする夢のようなツールです。
- **💡 こんな人におすすめ**: 高価なAI用パソコンを買わずに、ローカルで安全にLLM（大規模言語モデル）を試したい開発者やゲーマー。
- **概要**: 脱獄（Jailbreak）済みのPlayStation 5上で、LLM推論エンジンのデファクトスタンダードである「Llama.cpp」をネイティブ実行させるオープンソースプロジェクトです。開発者は @cobanov氏で、GitHubのトレンドランキングで急速にスター数を伸ばしています。
- **注目の理由・背景**: GPU不足と高価格化が続く中、コンシューマー向けゲーム機であるPS5の持つ強力なGPU（RDNA 2ベース、10 TFLOPs超）と大容量のユニファイドメモリ（16GB GDDR6）は、AIモデルを動かすハードウェアとして非常に魅力的です。このプロジェクトは、ゲーム機のポテンシャルをAI推論に全振りした点で大きな反響を呼んでいます。
- **主な機能・用途**:
  - Qwen 3.8 27B や Qwen 3.5 9B といった最新のオープンソースGGUFモデルをPS5のGPU上でロードし、推論を実行できます（例: Qwen 3.5 0.8Bで207トークン/秒、9Bで55トークン/秒の高速動作）。
  - PS5上でOpenAI互換のAPIサーバーを立ち上げることができ、同じWi-Fiネットワークに繋がったスマートフォンやPCから、PS5をAIサーバーとして利用可能です。
  - テレビ画面に特化した専用のユーザーインターフェース（UI）を備え、生成されるテキストをリアルタイムでテレビにストリーミング表示できます。
- **他の類似ツールとの比較**: 通常のPC上で動かす「Ollama」や「LM Studio」と似ていますが、最大の決定的な違いは「ハードウェアがPS5である」という点です。Macや高性能Windows PCを持っていないユーザーでも、所有しているPS5をサーバー化できるという強烈な独自性があります。
- **公式サイト/GitHub**: [https://github.com/cobanov/PS5LM](https://github.com/cobanov/PS5LM)

### **FLUX 3 Image Klein**

- **🔰 ひとことで言うと**: 写真と見間違えるほどリアルで高品質な画像を、AIが今までよりずっと賢く、きれいに作ってくれる最新の技術です。
- **💡 こんな人におすすめ**: クリエイター、デザイナー、または高品質な画像生成APIを自社のサービスに組み込みたい開発チーム。
- **概要**: Black Forest Labs (BFL.ai) が公開した次世代の画像生成AIモデルシリーズ「FLUX 3」の最新モデル（Klein）です。Hacker Newsのトップ記事にもランクインし、AI業界で大きな話題となっています。
- **注目の理由・背景**: これまでのFLUXシリーズに続くモデルとして、プロンプトの理解力（指示通りに画像を作る力）、文字（タイポグラフィ）の描写精度、そして物理的な正確さにおいて飛躍的な進化を遂げています。「Klein」という名称が示す通り、計算効率と品質のバランスを極限まで高めたモデルと推測されています。
- **主な機能・用途**: API経由での高品質な画像生成。特に、複雑なプロンプトや特定の空間配置を要求するような難しいお題に対しても、破綻の少ない画像を生成する能力に長けています。
- **他の類似ツールとの比較**: OpenAIのDALL-E 3やMidjourney v6と比較して、オープン性とプロンプトへの忠実度のチューニング方針で差別化を図っています。
- **公式サイト**: [https://bfl.ai/blog/flux-3-image-klein](https://bfl.ai/blog/flux-3-image-klein)

### **d2r-mobile**

- **🔰 ひとことで言うと**: 昔から人気の名作ゲーム（ディアブロ2）を、iPhoneやiPadでサクサク遊べるようにするファン待望のプログラムです。
- **💡 こんな人におすすめ**: Diablo II: Resurrectedのプレイヤー、iOSやmacOSでのゲームエミュレーション技術に興味があるプログラマー。
- **概要**: オープンソースで開発されている『Diablo II: Resurrected (D2R)』向けのiOS/macOS互換レイヤーです。ユーザーが所有するNintendo Switch版のゲームファイルを持ち込む（Bring your own game files）ことで、iPhoneやiPad、Mac上でネイティブに動作させることができます。
- **注目の理由・背景**: このツールは単なるエミュレーターではなく、「互換レイヤー」として機能するため、iOSデバイス上で60fpsのフルスピード動作を実現しています。フルタッチコントロールや新しいエンドゲームモードも実装されており、モバイル環境でのPC/コンソールゲームの移植技術として極めて高いクオリティを誇っています。GitHubで3,500以上のスターを獲得しています。
- **主な機能・用途**: ゲームファイルのロード、Metal APIを利用したグラフィック描画の最適化、モバイル向けのタッチインターフェースの提供。
- **他の類似ツールとの比較**: 汎用のSwitchエミュレーター（Ryujinxなど）とは異なり、特定のゲームに特化して命令を変換・最適化しているため、圧倒的なパフォーマンスを出せる点が最大の違いです。
- **公式サイト/GitHub**: [https://github.com/jhaizhou-ops/d2r-mobile](https://github.com/jhaizhou-ops/d2r-mobile)

React 19.3.1のリリースは、React Server Components（RSC）が実運用のフェーズに入り、通信レイヤー（Flight）の最適化など極めて高度なチューニングが行われていることを示しています。フロントエンド開発の複雑性は増していますが、その分得られるパフォーマンスの恩恵は大きくなっています。
また、「PS5LM」の登場は非常にシンボリックな出来事です。これまでLLMのローカル実行といえば、NVIDIAの高級GPUを搭載したPCかApple Silicon Macの独壇場でした。しかし、世界中に普及しているコンシューマーゲーム機（PS5）のGPUパワーをハックしてLlama.cppを動かすアプローチは、家庭の「余っているコンピューティングリソース」をAIインフラとして再定義する可能性を秘めています。
一方で、Axiosのプロトタイプ汚染やLangChainのSQLインジェクションなど、開発者が「当然安全だろう」と信頼して使っている基盤ライブラリの根幹を揺るがす脆弱性が相次いでいます。特にAxiosの脆弱性は、アプリケーションがJSONを処理する際の根本的な仕組みを突いたものであり、影響範囲は甚大です。便利なツールや基盤技術の進化を享受しつつも、「何を使っているか」「それにどんなリスクがあるか」を常に把握し、迅速にパッチを適用できる体制構築が不可欠です。

## **7. 📖 用語解説**

| 用語 | 解説 |
|------|------|
| **プロトタイプ汚染 (Prototype Pollution)** | JavaScript特有の弱点です。車の「設計図」にこっそり細工をして、新しく作られる全ての車に欠陥を持たせるような攻撃手法です。これを利用されると、プログラムのあらゆる設定が勝手に書き換えられてしまいます。 |
| **SQLインジェクション** | Webサイトの入力欄に、データベース（データを保存している金庫）への「秘密の命令」を混ぜ込む攻撃です。成功すると、パスワードを盗まれたり、データが全部消されたりします。 |
| **React Server Components (RSC)** | Webサイトを作るときに、画面の見た目を整える処理の一部を、ユーザーのスマホやPCではなく「裏側のサーバー」でやってしまおうというReactの新しい仕組みです。通信量が減り、サイトが速くなります。 |
| **GGUF形式** | AIモデル（LLM）のデータをギュッと圧縮して、普通のパソコンやスマートフォン、さらにはゲーム機などでも効率よく動かせるようにした新しいファイル形式です。 |
| **LLM (大規模言語モデル)** | ChatGPTのように、人間の言葉を理解して文章を作ったり、質問に答えたりする巨大なAIのことです。大量の文章を読んで学習しています。 |
| **エッジコンピューティング** | 遠くにある巨大なサーバー（クラウド）にデータを送らずに、自分の手元にあるパソコンやスマホ、ゲーム機などで直接データ処理を行う技術のことです。応答が速く、プライバシーも守りやすいのが特徴です。 |
