# **Onion Search Engine 調査レポート**

## **1. 基本情報**

* **ツール名**: Onion Search Engine
* **ツールの読み方**: オニオン・サーチ・エンジン
* **開発元**: Onion search engine
* **公式サイト**: [https://onionsearchengine.com/](https://onionsearchengine.com/)
* **関連リンク**:
  * レビューサイト: [Google Play](https://play.google.com/store/apps/details?id=com.onionsearchengine.onionsearchengine)
* **カテゴリ**: 検索エンジン
* **概要**: Onion Search Engineは、Torネットワーク、ディープウェブ、およびダークウェブ上のコンテンツを検索できる専用の検索エンジンである。ユーザーのプライバシーを尊重し、クッキーやJavaScript、サードパーティの追跡コードを含まない設計となっている。

## **2. 目的と主な利用シーン**

* **解決する課題**: 通常の検索エンジン（GoogleやBingなど）ではインデックスされない、Torネットワーク上の秘匿された情報（.onionドメイン）へのアクセスと検索機能を提供する。
* **想定利用者**: プライバシーを極度に重視するユーザー、セキュリティリサーチャー、Torネットワークの利用者。
* **利用シーン**:
  * Torネットワーク（ダークウェブ）内の特定のリソースや情報を検索する。
  * 追跡や監視を完全に回避して匿名でウェブ検索を行う。
  * .onionリンクの生存確認やコンテンツプレビューを行う。

## **3. 主要機能**

* **Torネットワーク検索**: 一般のブラウザではアクセスできないTorネットワーク（.onionドメイン）上のウェブサイトを検索可能。
* **プライバシー保護**: クッキーの不使用、JavaScriptの排除、サードパーティコードの排除により、ユーザートラッキングを防止。
* **コンテンツプレビュー**: 検索結果からサイトのタイトル、URL、およびコンテンツのプレビューを表示。
* **Androidアプリ**: モバイル（Android）向けの専用アプリを提供しており、Orbotなどと連携して動作する。
* **URL共有機能**: 検索で見つけたサイトのURLとタイトルを、メールやメッセージングアプリ経由で共有可能。

## **4. 動作原理・システム構成**

* **アーキテクチャ**: クラウドベースの検索インデクサーと、クライアントアプリ（Android等）またはTorネットワーク経由でアクセスするWebフロントエンドの構成。
* **主要コンポーネントとデータフロー**:
  * バックエンドのクローラーがTorネットワーク上の.onionサイトを巡回し、インデックスを作成。
  * クライアントはTor BrowserやOrbot等のVPN/プロキシを介してOnion Search Engineにアクセスし、検索クエリを送信。
  * 検索エンジンはインデックスから結果を返し、クライアントにプレビュー付きで表示する。
* **特筆すべき要素技術**:
  * クライアント側での完全なJavaScriptの排除によるセキュリティ強化。
  * Torネットワークプロトコルによる匿名通信のサポート。

## **5. 開始手順・セットアップ**

* **前提条件**:
  * アカウント作成は不要。
  * ウェブサイトの閲覧にはTor Browserが必要。
  * Androidデバイスの場合は、Torネットワークへ接続するためのOrbotまたはVPNアプリが必要。
* **インストール/導入**:

  ```bash
  # Androidの場合
  # Google Playストアから「Onion Search Engine」をインストール
  ```

* **初期設定**:
  * 特別な初期設定は不要。アプリを起動し、OrbotなどのTorプロキシを有効にするだけで利用可能。
* **クイックスタート**:
  * 検索バーにキーワードを入力して検索を実行する。

## **6. 特徴・強み (Pros)**

* Torネットワーク上のコンテンツを検索できる数少ない特化型検索エンジン。
* JavaScriptやクッキーを完全に排除しており、トラッキングのリスクが極めて低い。
* インストールしてすぐに使えるシンプルなインターフェース。
* モバイル向けアプリが用意されており、スマートフォン環境でもTor検索が容易。

## **7. 弱み・注意点 (Cons)**

* トラフィックをTorネットワーク経由にする必要があるため、一般的な検索エンジンに比べて動作が遅い。
* Torネットワークの性質上、検索結果に違法なコンテンツや悪意のあるサイトが含まれるリスクがあるため、自己責任での利用が求められる。
* 公式WebサイトはCloudflare等によるアクセス制限が厳しく、通常のブラウザからはアクセスしづらい場合がある。
* 日本語での検索精度は、英語の検索に比べると劣る可能性がある。

## **12. セキュリティとコンプライアンス**

* **データ管理**: クッキー不使用、ログの不保持を謳っており、ユーザーの検索履歴やIPアドレスは保存されないとしている。
* **準拠規格**: 公式サイトで公開されていない。

## **13. 操作性 (UI/UX) と学習コスト**

* **UI/UX**: 検索バーを中心とした非常にシンプルなデザインであり、Google検索などに慣れていれば迷わず操作できる。
* **学習コスト**: 低い。ただし、Torネットワークの概念やOrbotのセットアップなど、基盤となる技術についての基礎知識が必要。

## **14. ベストプラクティス**

* **効果的な活用法 (Modern Practices)**:
  * Androidデバイスで使用する場合、必ずOrbotを起動し、VPNモードまたはプロキシ設定を行ってからOnion Search Engineアプリを使用する。
  * パスワードや個人情報など、特定の個人と結びつくキーワードでの検索は避ける。
* **陥りやすい罠 (Antipatterns)**:
  * Tor Browserを使わずに通常のブラウザで検索結果の.onionリンクを開こうとすること（接続エラーになる）。
  * 検索結果のリンク先でJavaScriptを有効にしたり、ファイルのダウンロードを実行すること（匿名性が損なわれるリスクがある）。

## **18. 総評**

* **総合的な評価**:
  * Onion Search Engineは、Torネットワークやダークウェブ上のコンテンツへアクセスするためのニッチかつ特化したツールである。完全なJavaScriptやクッキーの排除など、プライバシーを極限まで保護する設計思想は評価できる。一方で、検索結果の質や動作速度についてはTorネットワークの制約を強く受けており、ユーザーからの評価も分かれている。
* **推奨されるチームやプロジェクト**:
  * セキュリティリサーチャー、サイバーインテリジェンス（CTI）調査チーム、および強力な匿名性を必要とする個人。
* **選択時のポイント**:
  * Androidデバイスでの利用が主であり、Orbotなどとの連携を前提とするなら良い選択肢となる。より一般的な表層ウェブの匿名検索が目的であれば、DuckDuckGoのOnion版などの方が利便性が高い。
