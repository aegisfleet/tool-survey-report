# **LivePortrait 調査レポート**

## **1. 基本情報**

* **ツール名**: LivePortrait
* **ツールの読み方**: ライブポートレート
* **開発元**: Kuaishou Technology
* **公式サイト**: [https://liveportrait.github.io](https://liveportrait.github.io)
* **関連リンク**:
  * GitHub: [https://github.com/KlingTeam/LivePortrait](https://github.com/KlingTeam/LivePortrait)
  * DeepWiki: [https://deepwiki.com/KlingTeam/LivePortrait](https://deepwiki.com/KlingTeam/LivePortrait)
  * CodeWiki: [https://codewiki.google/github.com/KlingTeam/LivePortrait](https://codewiki.google/github.com/KlingTeam/LivePortrait)
* **カテゴリ**: AI動画生成
* **概要**: LivePortraitは、静止画と駆動用動画（または画像）を組み合わせて、高品質かつ高効率なポートレートアニメーションを生成するオープンソースのAIツールである。人間のほか猫や犬にも対応し、細かな表情やポーズの制御（スティッチングやリターゲティング）が可能である。

## **2. 目的と主な利用シーン**

* **解決する課題**: 静止画からリアルで自然なアニメーションや話す顔の動画を低コスト・高効率で作成すること。
* **想定利用者**: クリエイター、動画編集者、AI開発者、エンターテインメント・映像プラットフォーム
* **利用シーン**:
  * 静止画アバターを使用した動画作成・配信
  * 既存の映像の表情や口の動きを別の音声や動きに合わせて修正（v2v: 動画から動画の編集）
  * 猫や犬などの動物画像の自動アニメーション化

## **3. 主要機能**

* **画像駆動モード (Image Driven)**: 1枚の静止画をソースとし、駆動用の画像や動画の動きを適用してアニメーション化する。
* **動画駆動・編集 (v2v)**: 入力に動画を使用し、別の駆動動画の動きに合わせて映像内の人物の動きを編集する。
* **動物モード (Animals Mode)**: 人間だけでなく、猫や犬の画像・映像にも対応した専用のアニメーション生成が可能。
* **リターゲティング制御**: 目の大きさ、唇の開き具合などを精密にコントロールする。
* **スティッチング**: 頭部のアニメーションを元の画像・映像の背景や肩の動きに自然に合成（スティッチ）する機能。
* **音声・動画の結合**: 音声データや駆動ビデオの自動クロップ、テンプレート化を行い推論を高速化・プライバシー保護を行う機能。
* **部分制御 (Regional Control)**: 特定の領域（目、口など）のみの動きを個別に制御する。

## **4. 動作原理・システム構成**

* **アーキテクチャ**: ローカル環境（またはクラウドGPU環境）で動作するクライアント・サーバー構成（主にPythonとPyTorchベースのスクリプト、Gradioを用いたWeb UI）。
* **主要コンポーネントとデータフロー**:
  * 入力画像/動画から特徴点や表情を抽出（InsightFace等のモデルを使用）。動物モードではX-Poseを利用したキーポイント検出が行われる。
  * 駆動データ（動画やポーズデータ）から抽出したモーションを、ターゲット画像の特徴量にリターゲティングする。
  * 暗黙的（Implicit）なキーポイントベースの枠組みを使用し、計算効率を高め、スティッチング処理を経て最終的な動画をレンダリングして出力する。
* **特筆すべき要素技術**:
  * PyTorchおよびCUDAを用いたディープラーニング推論。
  * `torch.compile`を利用した推論の高速化（初回実行時に最適化プロセスが走り、2回目以降20-30%高速化される）。
  * 依存関係としてFFmpeg（動画処理）やcondaによる環境分離が利用されている。

## **5. 開始手順・セットアップ**

* **前提条件**:
  * OS: Linux, Windows, または macOS (Apple Silicon対応)
  * ランタイム: Python 3.10
  * 依存ツール: git, conda, FFmpeg
* **インストール/導入**:

  ```bash
  git clone https://github.com/KlingTeam/LivePortrait
  cd LivePortrait
  conda create -n LivePortrait python=3.10
  conda activate LivePortrait
  ```

* **初期設定**:
  * 動物モードを利用する場合は、依存関係である `X-Pose` のカスタムオペレータ（MultiScaleDeformableAttention）をビルドする必要がある。
* **クイックスタート**:
  * 画像ソースと動画で推論を実行: `python inference.py -s assets/examples/source/s9.jpg -d assets/examples/driving/d0.mp4`
  * GradioのWeb UIを起動: `python app.py`

## **6. 特徴・強み (Pros)**

* 高解像度かつ自然な表情や瞬き、首の動きなどを実現しつつ、コンシューマ向けGPUでも高速に推論が可能。
* スティッチング技術や目の大きさ・口の開き具合といったリターゲティング制御により、出力結果を細かく調整できる。
* ComfyUIやStable Diffusion WebUIの拡張機能など、コミュニティ主導の派生プロジェクトが多数存在し、エコシステムが強力である。
* 人間だけでなく、犬や猫の表情アニメーションにも公式対応している。

## **7. 弱み・注意点 (Cons)**

* ベースとなるコードはMITライセンスだが、顔検出に使用されている InsightFace モデルが非商用（学術研究目的）ライセンスであるため、商用利用する場合は代替モデルへの差し替えが必要。
* Python、CUDA、FFmpeg等のセットアップが必要であり、環境構築のハードルがある（ただしWindows向けの1-click installerも提供されている）。
* 動物モードはLinuxおよびWindowsのNVIDIA GPU環境のみでテストされており、macOS等の環境では公式サポート・テストされていない。

## **12. セキュリティとコンプライアンス**

* **認証**: オープンソースソフトウェアであり、ツール自体に認証機能はない。
* **データ管理**: ローカル環境で実行する場合、データはすべてローカル内に保存される。プライバシー保護を目的としたモーショントンプテート（`.pkl`）の作成機能がある。
* **準拠規格**: 公式サイトでは公開されていない。個別の問い合わせが必要。

## **13. 操作性 (UI/UX) と学習コスト**

* **UI/UX**: CLIでの操作に加え、Gradioを用いたWeb UIが提供されており、ブラウザ上から直感的にソース画像と駆動動画を設定して生成できる。
* **学習コスト**: スクリプトの実行やGradioの利用は簡単だが、初期の環境構築（Python, CUDA, FFmpeg）には一定の開発者向け知識が要求される。

## **14. ベストプラクティス**

* **効果的な活用法 (Modern Practices)**:
  * 複数回の推論を行う場合、プライバシー保護および推論の高速化のために駆動動画からモーションテンプレート（`.pkl`）を事前に抽出して利用することが推奨される。
  * `torch.compile`（`--flag_do_torch_compile`オプション）を有効化し、推論速度を20〜30%向上させる（初回のみ最適化に時間がかかる）。
* **陥りやすい罠 (Antipatterns)**:
  * 商用プロジェクトでそのまま利用すること。InsightFaceモデルのライセンス（非商用のみ）に違反するリスクがあるため、商用利用時は代替の顔検出モデル（MediaPipeなど）に置き換える必要がある。
  * macOS (Apple Silicon) 環境で動物モードを利用しようとすること（公式テスト対象外でありエラーになる可能性がある）。

## **18. 総評**

* **総合的な評価**:
  * LivePortraitは、静止画や動画を用いた顔のアニメーション生成において、最高クラスの品質と効率性を誇るオープンソースツールである。人間の顔だけでなく動物にも対応し、リターゲティングや部分制御による高度な調整機能も備えているため、非常に強力である。
* **推奨されるチームやプロジェクト**:
  * AI動画生成技術を活用したい開発チーム、VTuberやアバターを扱うエンターテインメント企業、クリエイティブな表現を追求する個人の動画クリエイター。
* **選択時のポイント**:
  * ローカル環境で無料で高品質な動画生成を行いたい場合には第一の選択肢となるが、商用利用を前提とする場合はライセンス上の制約（InsightFaceモデル）を解決する技術的・法的なリソースがあるかを確認する必要がある。
