# **Mesh Avatar Studio 調査レポート**

## **1. 基本情報**

* **ツール名**: Mesh Avatar Studio
* **ツールの読み方**: メッシュ アバター スタジオ
* **開発元**: shinshin86
* **公式サイト**: [https://github.com/shinshin86/mesh-avatar-studio](https://github.com/shinshin86/mesh-avatar-studio)
* **関連リンク**:
  * GitHub: [https://github.com/shinshin86/mesh-avatar-studio](https://github.com/shinshin86/mesh-avatar-studio)
* **カテゴリ**: アバター作成
* **概要**: 1枚のイラストから、まばたき・口パク・首振り・呼吸・髪の揺れをする2Dメッシュアバターを作るオープンソースツール。アバターの作成作業のベース部分はコーディングエージェント（Claude CodeやCodex）が行い、細かい調整はローカルのエディタでプレビューを見ながら行う。

## **2. 目的と主な利用シーン**

* **解決する課題**: 2Dアバターを作成する際の複雑なモデリングやアニメーション設定の手間を軽減する
* **想定利用者**: 開発者、クリエイター、VTuber
* **利用シーン**:
  * 1枚の静止画イラストから簡単にアニメーションするアバターを作成したい場合
  * AIコーディングエージェントを活用してアバター作成のワークフローを自動化したい場合

## **3. 主要機能**

* **AIエージェントによるアバター作成**: Claude CodeやCodexに画像を渡し、指示通りに処理させることで、リグの配置や画像のレイヤー切り出しを自動化。
* **ローカルエディタでのプレビュー調整**: ブラウザ上で動作するローカルエディタを提供し、パーツを選んでドラッグする直感的な操作で調整が可能。
* **ポーズとリップシンクのテスト**: エディタ上で顔の向き、傾き、目の開閉などの「ポーズ確認」や、母音ごとの口の形を確認する「口の動き（リップシンク）」テストが可能。
* **描き分け画像の自動生成連携**: Codexなどの画像生成機能を利用し、閉じた目や母音ごとの口の絵（描き分け画像）を生成して取り込み、より自然な表情を実現。
* **WebGLによるメッシュ変形**: WebGLを利用して2Dメッシュを変形させ、呼吸や髪の揺れなどのアニメーションを描画。

## **4. 動作原理・システム構成**

* **アーキテクチャ**: ローカル実行型のクライアントアプリケーション
* **主要コンポーネントとデータフロー**:
  * AIエージェント（Claude Code / Codex）が画像を解析してプロジェクトファイルを生成。
  * ローカルのNode.js（Viteベース）サーバーがエディタUIをブラウザに提供し、プロジェクトを読み込んで表示。
* **特筆すべき要素技術**:
  * フロントエンド構築には React を採用
  * 2D描画および変形処理に WebGL を使用
  * エージェント作業はリポジトリのドキュメント（`docs/agent-guide.md`）に依存

## **5. 開始手順・セットアップ**

* **前提条件**:
  * Node.js 22.17 以上が必要
  * Claude Code や Codex などのAIコーディングエージェントの利用環境
* **インストール/導入**:

  ```bash
  npm install
  ```

* **初期設定**:
  * 特になし
* **クイックスタート**:
  ```bash
  npm run dev
  ```
  * コマンド実行後、ターミナルに表示される URL (例: `http://127.0.0.1:5173/`) をブラウザで開く。

## **6. 特徴・強み (Pros)**

* AIエージェントを活用することで、専門的な技術がなくても1枚の画像から高品質なアバターを生成可能
* 調整作業をブラウザ上のGUIエディタで直感的に行える
* オープンソースであり、ローカル環境で動作するため、プライベートな画像の処理も安全に行える

## **7. 弱み・注意点 (Cons)**

* AIコーディングエージェント（Claude Code または Codex）を自前で用意・セットアップする必要がある
* 複雑な表現（高度な3D回転など）には対応していない可能性がある
* 開発途中であり、日本語対応はREADMEなどの一部ドキュメントに留まる

## **13. 操作性 (UI/UX) と学習コスト**

* **UI/UX**: Webベースのエディタにより、パーツのドラッグ操作などで直感的に調整可能。変更が即座にプレビューに反映されるためわかりやすい。
* **学習コスト**: エディタ自体の操作は容易だが、前段階としてAIエージェント（Claude Code等）に適切な指示を出すための準備や理解が必要。

## **14. ベストプラクティス**

* **効果的な活用法 (Modern Practices)**:
  * 入力画像として、正面向きのバストアップで背景が透明な PNG 画像を使用すると、最適な結果が得られる。
* **陥りやすい罠 (Antipatterns)**:
  * 目や手の輪郭、髪のマスク領域などを変更した後に「保存してレイヤーを作り直す」手順をスキップすると、表示が乱れる場合がある。
