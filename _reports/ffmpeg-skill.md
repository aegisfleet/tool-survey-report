# **ffmpeg-skill 調査レポート**

## **1. 基本情報**

* **ツール名**: ffmpeg-skill
* **ツールの読み方**: エフエフエムペグスキル
* **開発元**: kajisho5
* **公式サイト**: [https://github.com/kajisho5/ffmpeg-skill](https://github.com/kajisho5/ffmpeg-skill)
* **関連リンク**:
  * GitHub: [https://github.com/kajisho5/ffmpeg-skill](https://github.com/kajisho5/ffmpeg-skill)
* **カテゴリ**: 開発者ツール
* **概要**: Claude Code、Cursor、Codexなどのコーディングエージェントにローカルでの動画・音声編集機能を付与するAgent Skillです。42個のFFmpegツールを提供し、MCPサーバーとしても機能します。

## **2. 目的と主な利用シーン**

* **解決する課題**: AIエージェントが動画や音声ファイルの内容を解析・編集・最適化できないという課題を、ローカルのFFmpegを呼び出すことで解決する。
* **想定利用者**: コーディングエージェント（Claude Code等）を利用する開発者、ローカルで動画のバッチ処理や自動編集を行いたいユーザー。
* **利用シーン**:
  * AIエージェントに指示して動画のカット、結合、無音部分の削除を自動で行う
  * YouTubeやTikTokなどのプラットフォーム仕様に合わせた動画の自動リサイズ・エンコード
  * 字幕生成、モーションテキスト、テロップの自動挿入

## **3. 主要機能**

* **プローブと分析**: 動画や音声のメタデータを解析し、色空間（HDR/SDR）や音量などを測定・視覚化する。
* **動画編集**: 動画のフレーム単位でのカット、フェード処理を伴う結合、指定の解像度やアスペクト比へのフィッティング。
* **音声処理**: ノイズ除去、ダッキング、ラウドネス正規化、複数カメラの音声波形ベースの自動同期。
* **テロップ・グラフィックス**: 字幕の焼き込み（カラオケ風ハイライト含む）、ローワーサード等のモーションテキスト作成。
* **プロジェクト出力**: カットからエクスポートまでの複数の編集指示を1つのJSONで定義し、一括でレンダリング・出力する。
* **配信前チェック**: 出力ファイルが対象プラットフォーム（YouTube, Shorts, TikTokなど）の仕様に準拠しているかを自動チェックする。
* **バッチ処理**: 指定したフォルダ内のファイルに対して、レシピやプロジェクトを一括適用する。

## **4. 動作原理・システム構成**

* **アーキテクチャ**: ローカルファーストのクライアント・サーバー構成（CLIツール群＋MCPサーバー）。
* **主要コンポーネントとデータフロー**:
  * AIエージェントはMCP（Model Context Protocol）経由、または直接CLI経由でスクリプトを呼び出す。
  * スクリプト群（Python）はローカル環境にインストールされた `ffmpeg` および `ffprobe` バイナリのサブプロセスを起動して実際のメディア処理を実行する。
  * `contract --json` コマンドが `argparse` の定義から実行時にMCPスキーマやツールのコントラクトを自動生成し（SPEC: Self-Producing Execution Contract）、AIがパラメータの仕様を正確に理解できるようにしている。
* **特筆すべき要素技術**:
  * **MCP (Model Context Protocol)**: `npx ffmpeg-skill` でサーバーとして起動でき、JSON-RPCでエージェントと通信。
  * **SPEC (Self-Producing Execution Contract)**: ツールの入出力スキーマがコード（argparse）から動的に生成され、乖離を防ぐ仕組み。

```mermaid

    B -->|サブプロセス起動| C[ffmpeg / ffprobe\nバイナリ]
```

## **5. 開始手順・セットアップ**

* **前提条件**:
  * FFmpeg 5.0以上（6.1以上推奨、3.0からは6.1必須）
  * Python 3.10以上推奨（標準ライブラリのみで動作）
  * Node.js 16以上（インストーラーの実行に必要）
* **インストール/導入**:

  ```bash
  # Claude Code向けインストール
  npx ffmpeg-skill

  # Cursor向けインストール
  npx ffmpeg-skill --cursor
  ```

* **初期設定**:
  * PATH上に `ffmpeg-full` があることを確認する（macOSのHomebrewなどの場合、追加のフィルタモジュールが含まれている必要がある）。
* **クイックスタート**:
  * 動作環境のチェックと提供ツールの確認：
  ```bash
  npx ffmpeg-skill doctor
  npx ffmpeg-skill contract --json
  ```

## **6. 特徴・強み (Pros)**

* AIエージェントに特化した設計で、厳密なワークフロー（プローブ→編集→チェック→検証）を組み込んでいる。
* クラウドサービスを使用せずローカルのFFmpegを使用するため、大容量の動画ファイルをアップロードする必要がなくセキュアで高速。
* スクリプトの引数定義からMCPスキーマが自動生成されるため、AIエージェントが誤った引数を指定するリスクが低減される（SPEC）。
* 事前にプローブを行い、可能な限りロスレスで処理（再エンコードを避ける）し、最後にバリデーションを行うという手順をAIに強制できる。

## **7. 弱み・注意点 (Cons)**

* 高度な機能（`libass`, `zscale`など）を使用するため、FFmpegの完全なビルド（`ffmpeg-full`等）をユーザー自身で用意する必要がある。
* CLI自体はPythonだが、インストーラーやエージェント側でNode.jsが要求される場合がある。
* 現在GPUエンコード（HWアクセラレーション）はApple Silicon上のVideoToolboxに限定されている。

## **13. 操作性 (UI/UX) と学習コスト**

* **UI/UX**: エンドユーザーはAIエージェントとのチャットUIを通じて自然言語で指示を出すため、複雑なFFmpegコマンドを直接書く必要がなく非常に直感的。
* **学習コスト**: AIエージェントに「動画の無音をカットしてTikTok向けに書き出して」と伝えるだけで良いため、FFmpeg自体の学習コストはゼロに等しい。ただし、環境構築にはある程度の知識が必要。

## **14. ベストプラクティス**

* **効果的な活用法 (Modern Practices)**:
  * 編集内容を `render.py` を用いた宣言的なJSONプロジェクトとして記述することで、処理の再現性と自動化を高める。
  * `check.py` を用いて、SNSプラットフォームの配信要件を満たしているかを最後に必ずバリデーションする。
* **陥りやすい罠 (Antipatterns)**:
  * パス上に機能が制限されたFFmpeg（例: macOSにおけるHomebrewの標準 `ffmpeg`）が配置されていると、一部機能がエラーになる。必ず `doctor` コマンドで検証する。

## **18. 総評**

* **総合的な評価**:
  * ffmpeg-skillは、自然言語による動画編集の可能性を大きく広げるツールです。AIエージェントに直接FFmpegコマンドを書かせるのではなく、検証済みの42のツール群と厳格なコントラクト（SPEC）を介在させることで、ハルシネーションを防ぎ、確実なメディア処理を実現しています。
* **推奨されるチームやプロジェクト**:
  * 開発者やAIエージェントを活用しているクリエイター、大量の動画コンテンツを自動処理したいプロジェクトチームに強く推奨されます。
* **選択時のポイント**:
  * クラウド型の動画処理APIを利用したくない（あるいはコストを抑えたい、機密性を保ちたい）場合に、ローカルで完結する強力な自動化エンジンとして最良の選択肢となります。
