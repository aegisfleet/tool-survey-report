# **Audio Studio MCP 調査レポート**

## **1. 基本情報**

* **ツール名**: Audio Studio MCP
* **ツールの読み方**: オーディオ スタジオ エムシーピー
* **開発元**: KanaWorks_AI
* **公式サイト**: [https://kanaworksai-hue.github.io/audio-studio-mcp/](https://kanaworksai-hue.github.io/audio-studio-mcp/)
* **関連リンク**:
  * GitHub: [https://github.com/kanaworksai-hue/audio-studio-mcp](https://github.com/kanaworksai-hue/audio-studio-mcp)
* **カテゴリ**: MCPサーバー/基盤
* **概要**: Claude Code、Claude Desktop、CursorなどのMCPクライアントから、自身のMacやWindows PC上でBGMや効果音を生成・編集できるローカルAIサウンドスタジオです。クラウドサービスやAPIキーは不要で、Stable Audio 3を利用して無料で音声を生成できます。

## **2. 目的と主な利用シーン**

* **解決する課題**: クラウドのAI音声生成サービスの利用コストやプライバシーの懸念を払拭し、ローカル環境で手軽かつ無制限にゲームBGMや効果音を生成・編集したいという課題。
* **想定利用者**: ゲーム開発者、動画クリエイター、AIエージェントを利用するエンジニア
* **利用シーン**:
  * Claude CodeなどのAIエージェントに対して自然言語で指示し、ゲームの場面に合わせたループBGMを生成する。
  * 動画編集で必要な特定の環境音や効果音（例：ガラスが割れる音）を即座に作成する。
  * 既存の音声トラックの長さを延長したり、特定の時間範囲を再生成（インペイント）して調整する。

## **3. 主要機能**

* **音声生成機能 (generate_audio)**: テキストプロンプトからBGM、楽器のループ、効果音を生成します。1回の呼び出しで1〜4つのバリエーションを作成でき、BPM指定や詳細な効果音パラメータ（音源、アクション、素材、空間）の設定が可能です。
* **音声編集機能 (edit_audio)**: クリップ全体のスタイル変更（variation）、特定の時間範囲の再生成（inpaint）、トラックの延長（continue）などの高度な編集が行えます。
* **音声処理・書き出し機能 (process_audio)**: 無音部分のトリミング、モノラル化、リサンプリング、シームレスなループ化、フェードイン/アウト、ピーク正規化や音量（LUFS）の調整を行い、WAV、OGG、FLAC形式で書き出します。入力データは変更されず非破壊処理されます。
* **モデルのメモリ解放 (unload_models)**: 使用後のモデルメモリを即座に解放する機能を備え、リソースを効率的に管理できます。
* **プロンプトの自動最適化**: サーバー側がMCPクライアントに対してStable Audio 3の公式プロンプトフォーマットを教えるため、自然言語の指示が自動的に適切なプロンプトに変換されます。
* **完全なローカル実行**: クラウドへのアップロードを一切行わず、すべての処理をローカルマシンで完結させます。出力ファイルには生成時のプロンプトやシード値を記録したJSONファイルが添付され、再現性を確保しています。

## **4. 動作原理・システム構成**

* **アーキテクチャ**: ローカルファーストのMCPサーバー構成
* **主要コンポーネントとデータフロー**:
  * クライアント（Claude Code等）がMCPを通じて生成や編集の指示をサーバーに送信します。
  * サーバーはローカルのGPU（Apple SiliconのMLX、またはNVIDIA GPUのPyTorch）にロードされたStable Audio 3モデルを利用して音声を生成します。
  * 生成された音声データはローカルのディスク（`outputs/` ディレクトリ）に44.1 kHz 24-bitステレオのWAVファイルとして書き出され、設定が記録された `.json` ファイルが同梱されます。
* **特筆すべき要素技術**:
  * **MLX**: macOS（Apple Silicon）上で高速に動作するための機械学習フレームワーク。
  * **PyTorch / CUDA**: Windows上でNVIDIA GPUの性能を引き出すためのフレームワーク。
  * **Model Context Protocol (MCP)**: AIエージェントと外部ツールを安全に接続するための標準プロトコル。

## **5. 開始手順・セットアップ**

* **前提条件**:
  * macOS: Apple Silicon Mac (M1以降)、16 GB以上のRAMを推奨。gitとffmpeg。
  * Windows: 64-bit Windows 10/11、NVIDIA GPU (VRAM 8GB以上、RTX 3060 12GBでテスト済み)。gitとffmpeg。Hugging Faceの無料アカウント（モデルのダウンロード用）。
* **インストール/導入**:

  ```bash
  # リポジトリのクローン
  git clone https://github.com/kanaworksai-hue/audio-studio-mcp.git
  cd audio-studio-mcp

  # macOSの場合
  ./install.sh

  # Windowsの場合
  powershell -ExecutionPolicy Bypass -File install.ps1
  ```

* **初期設定**:
  * macOSの場合は自動でHugging Faceからモデルがダウンロードされます。
  * Windowsの場合は、Hugging Faceのサイトで利用規約に同意し、ターミナルで `hf auth login` を実行して認証を行う必要があります。
* **クイックスタート**:
  * インストールスクリプトの最後に表示されるコマンド（例: `claude mcp add --scope user audio-studio -- /path/to/audio-studio-mcp/.venv/bin/audio-studio-mcp`）を使用して、クライアントにMCPサーバーを登録します。その後、クライアントから自然言語で音声生成を指示します。

## **6. 特徴・強み (Pros)**

* クラウドサービスに依存せず、API利用料やデータプライバシーの心配がない完全なローカル動作。
* Apple Silicon (MLX) と NVIDIA GPU (PyTorch) に最適化されており、専用の環境で高い生成速度を実現。
* 音声生成だけでなく、ゲームエンジンや動画編集ソフトですぐに使える形式（シームレスループ、LUFS正規化、OGG出力など）への後処理が充実している。
* プロンプトエンジニアリングが組み込まれており、ユーザーは専門的なプロンプトの記述方法を知らなくても高品質な結果を得られる。

## **7. 弱み・注意点 (Cons)**

* ローカルマシンに高いスペック（Macなら16GB RAM以上、WindowsならVRAM 8GB以上のGPU）が要求される。
* Windows版の初期セットアップ時に、Hugging Faceのライセンス同意とトークン認証の手間がかかる。
* モデルの仕様上、ボーカル（歌声）や意味のある歌詞を含む楽曲の生成はできない。
* Intel MacやAMD GPUを搭載した環境は現在非サポート。

## **12. セキュリティとコンプライアンス**

* **認証**: ツール自体の利用に認証は不要ですが、Windows環境でのモデルダウンロード時にHugging Faceへのアクセストークン認証が必要です。
* **データ管理**: インターネットへのデータアップロードは一切行われず、生成された音声やプロンプトはすべてローカルストレージ（`outputs/` フォルダ）に保存されます。
* **準拠規格**: ローカル実行のため特定のセキュリティ規格への準拠は求められませんが、機密性の高いプロジェクトでも安全に使用できます。

## **13. 操作性 (UI/UX) と学習コスト**

* **UI/UX**: 独自のGUIを持たず、AIエージェント（Claude Codeなど）のチャットUIを通じて自然言語で操作します。複雑なパラメータ設定などをAIが代行するため、直感的な操作が可能です。
* **学習コスト**: クライアントへのMCPサーバー登録さえ完了すれば、あとは日常言語で「カフェのBGMを作って」などと指示するだけなので、学習コストは非常に低いです。

## **14. ベストプラクティス**

* **効果的な活用法 (Modern Practices)**:
  * クライアントとサーバーを同一プロセスで起動・終了させるのではなく、ローカルHTTPサーバーモード（`--http 8765 --preload`）で常駐起動させておくことで、セッション間のモデル再読み込み時間を短縮できます。
  * BGMだけでなく、効果音（SFX）生成時には「source」「action」「material」「space」などの要素をプロンプトに盛り込むことで、より意図したサウンドを得やすくなります。
* **陥りやすい罠 (Antipatterns)**:
  * MP3形式は仕様上先頭と末尾にパディングが追加されるため、シームレスなループ再生には適しません。ループ素材は必ずWAVまたはOGGで書き出すように指示することが重要です。
  * 「15秒でクライマックスを迎える」といった細かい時間指定はモデルの仕様上追従しにくいため、まずは長めに生成してから `inpaint` や `trim` 機能で後加工するのが推奨されます。

## **18. 総評**

* **総合的な評価**:
  Audio Studio MCPは、昨今注目を集めるMCP (Model Context Protocol) を活用し、AIエージェントに「音を作る・編集する」能力を付与する画期的なツールです。クラウドAPIに依存せず、MacやWindowsのローカルリソースを活用することで、プライバシーを保ちながらコストゼロで音声生成を可能にした点は高く評価できます。生成から後処理（ループ化、ノーマライズ等）まで一貫して行えるため、実用性が非常に高いです。
* **推奨されるチームやプロジェクト**:
  インディーゲーム開発チーム、個人で動画制作を行うクリエイター、ローカルで完結するAIエージェントの開発・運用を行っているエンジニアに特に推奨されます。
* **選択時のポイント**:
  生成したい音声がインストゥルメンタル（BGM）や環境音・効果音であれば、このツールは最良の選択肢の一つとなります。ただし、ボーカル入りの楽曲生成が必要な場合や、ローカルマシンのGPU性能が不足している場合は、Sunoなどのクラウド型APIの利用を検討する必要があります。
