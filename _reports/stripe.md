# **Stripe 調査レポート**

## **1. 基本情報**

* **ツール名**: Stripe
* **ツールの読み方**: ストライプ
* **開発元**: Stripe, LLC
* **公式サイト**: [https://stripe.com/](https://stripe.com/)
* **関連リンク**:
  * GitHub: [https://github.com/stripe](https://github.com/stripe)
  * ドキュメント: [https://docs.stripe.com/](https://docs.stripe.com/)
* **カテゴリ**: 決済代行サービス
* **概要**: インターネット経済のインフラストラクチャを構築する、開発者向けの総合決済プラットフォーム。数行のコードで決済処理を組み込むことができ、決済以外にもサブスクリプション管理、不正対策、会社設立支援などビジネスに必要な多様な金融機能を提供する。

## **2. 目的と主な利用シーン**

* **解決する課題**: 複雑な決済システム構築の手間を省き、オンライン決済、継続課金、グローバル展開を迅速かつ安全に行う。
* **想定利用者**: スタートアップ、SaaS企業、プラットフォーム事業者、ECサイト運営者、エンジニア
* **利用シーン**:
  * SaaSの月額サブスクリプションや従量課金システム（Stripe Billing）の構築
  * CtoCプラットフォームやマーケットプレイスにおける複雑な資金移動（Stripe Connect）の実現
  * ノーコードの「Payment Links（支払いリンク）」を使った迅速な決済機能の立ち上げ

## **3. 主要機能**

* **Stripe Payments**: クレジットカード決済、各種ウォレット（Apple Pay、Google Pay）、銀行振込など135以上の通貨でのオンライン・対面決済を処理する。
* **Stripe Billing**: 定期課金、従量課金、段階的課金など複雑なサブスクリプションモデルを構築し、インボイスを自動発行する。
* **Stripe Connect**: プラットフォームやマーケットプレイス向けに、複数のユーザーや販売者間での支払いのルーティングや入金管理を行う。
* **Stripe Radar**: 機械学習を用いてリアルタイムに不正利用を検知し、チャージバックのリスクを軽減する。
* **Stripe Terminal**: 実店舗や対面ビジネス向けに、オンライン決済基盤と統合されたカードリーダー（決済端末）を提供する。
* **Stripe Atlas**: 米国での会社設立手続きを簡素化し、銀行口座開設やStripeアカウント発行を数日で完了させる。

## **4. 動作原理・システム構成**

* **アーキテクチャ**: クラウド完結型SaaS（APIベースの決済ゲートウェイ）
* **主要コンポーネントとデータフロー**:
  * Stripeの提供するUIコンポーネント（Stripe Elements）またはCheckoutをフロントエンドに組み込む。
  * 顧客の決済情報（クレジットカード番号等）は加盟店サーバーを経由せず、直接Stripeのサーバーへ送信され、トークン（PaymentMethod）化される。
  * 加盟店のバックエンドサーバーは、そのトークンを用いてStripeのAPIを叩き、決済（PaymentIntent）を完了させる。
* **特筆すべき要素技術**:
  * **Stripe Elements**: PCI DSSに準拠しつつ、サイトのデザインに合わせて柔軟にカスタマイズできる決済UIコンポーネント。顧客データをセキュアに扱う（非保持化）。
  * **Webhook**: 決済完了やサブスクリプション更新などのイベントを加盟店サーバーにリアルタイムで通知する非同期通信の仕組み。

## **5. 開始手順・セットアップ**

* **前提条件**:
  * 本番環境での利用には、企業情報・代表者情報の登録と審査（オンラインで即時～数日）が必要。
* **インストール/導入**:

  ```bash
  # Node.js環境の場合のSDKインストール例
  npm install stripe
  ```

* **初期設定**:
  * Stripeダッシュボードからアカウントを作成し、APIキー（公開キー、シークレットキー）を取得する。
* **クイックスタート**:
  * 最も簡単な方法は、ダッシュボードから「支払いリンク（Payment Links）」を作成し、そのURLを顧客に共有するだけで、ノーコードで決済を受け付けることができる。

## **6. 特徴・強み (Pros)**

* **圧倒的な開発者体験 (DX)**: 直感的なAPI、洗練されたドキュメント、各言語の公式ライブラリ、CLIツールが揃っており、エンジニアが最も組み込みやすい決済サービスである。
* **初期費用・月額固定費ゼロ**: 決済が発生した分だけの従量課金（トランザクションごとの手数料）であるため、スタートアップや新規事業でリスクなく導入できる。
* **グローバル対応と拡張性**: 135以上の通貨に対応し、国を跨いだビジネス展開が容易。決済だけでなく、サブスクリプション、不正検知、税金計算など事業成長に合わせた機能拡張（エコシステム）が1つのプラットフォームに統合されている。
* **スピード感**: アカウント作成から数分でテスト決済を実行でき、煩雑な書面手続きなしに即日でオンライン決済を本番稼働できる。

## **7. 弱み・注意点 (Cons)**

* **国内特有の決済手段の網羅性**: クレジットカード決済やApple Pay/Google Payには強みを持つが、一部の国内キャリア決済や多様なコンビニ決済、マイナーなPay系決済を全て網羅しているわけではないため、国内ローカルの決済手段を完璧に揃えたい場合は国内専業の代行業者に劣る場合がある。
* **サポート体制**: 電話サポートがなく、メールやチャットベースとなるため、トラブル時に即座の電話対応を求める企業には不向きとされる。
* **アカウント凍結リスク**: 利用規約違反やチャージバック率が基準を超えた場合など、機械的な判定でアカウントが突然制限・凍結されるリスクが（他の外資系SaaS同様に）一定存在する。

## **8. 料金プラン**

| プラン名 | 料金 | 主な特徴 |
|---------|------|---------|
| **標準の決済手数料 (Pay As You Go)** | 初期0円・月額0円 | 決済ごとに3.6%（※カードブランドにより異なる）が基本。初期費用や月額固定費は無料。 |
| **カスタム料金 (エンタープライズ)** | 個別見積もり | 取扱高が多い企業や独自のビジネスモデルを持つ企業向けにボリュームディスカウント等を設定。 |

* **課金体系**: 決済が成功したトランザクション単位での従量課金。その他、Stripe Billing（サブスクリプション管理）やStripe Radar（不正検知）など各プロダクトの利用状況に応じた従量課金が発生する。
* **無料トライアル**: すべての開発・テスト環境（テストキー）が無料で利用可能。

## **12. セキュリティとコンプライアンス**

* **認証**: Stripe ElementsやCheckoutを利用することで、加盟店側でカード情報を保持しない非保持化を容易に実現（PCI DSSレベル1プロバイダ）。
* **データ管理**: 高度な暗号化による通信と保存。
* **準拠規格**: PCI DSS レベル1、SOC 1 / SOC 2、GDPR、PSD2（欧州の決済サービス指令）、各種アンチマネーロンダリング（AML）規制に準拠。

## **13. 操作性 (UI/UX) と学習コスト**

* **UI/UX**: 加盟店向けのダッシュボードは非常に洗練されており、売上の分析、顧客管理、サブスクリプションのステータス変更などが直感的に行える。顧客向けの決済画面（Checkout）もモバイル対応で高いコンバージョン率を誇る。
* **学習コスト**: 決済の概念（Intent、Customer、PaymentMethodなど）を理解する必要はあるが、ドキュメントの質が高くチュートリアルも豊富であるため、エンジニアにとっての学習コストは低い。非エンジニアでもノーコード機能（Payment Links）を利用すれば学習コストほぼゼロで利用できる。

## **14. ベストプラクティス**

* **効果的な活用法 (Modern Practices)**:
  * **PaymentIntentとWebhookの活用**: トランザクションの状態遷移を確実にトラッキングするため、PaymentIntent APIを利用し、Webhookによる非同期の成功通知を受け取って自社DBを更新する堅牢なフローを構築する。
  * **Stripe Checkoutの利用**: セキュリティ要件（PCI DSS）の対応コストを下げるため、自前で決済フォームを作らず、StripeがホストするCheckoutページを積極的に活用する。
* **陥りやすい罠 (Antipatterns)**:
  * **Webhookの署名検証漏れ**: Webhookのエンドポイントを公開する際、Stripeからの正当なリクエストであるかを確認する「署名検証」を実装し忘れると、悪意のある攻撃者から偽の決済成功通知を送られるリスクがある。

* **総合的な評価**:
  Stripeは、「インターネット経済のインフラ」を標榜する通り、決済機能の組み込みやすさ（開発者体験）、スケーラビリティ、エコシステムの広さにおいて世界最高峰のプラットフォームである。単なる決済代行にとどまらず、Billing、Connect、Radarなどの周辺プロダクトを組み合わせることで、複雑なビジネスモデルも迅速に構築・運用できる。
* **推奨されるチームやプロジェクト**:
  開発スピードを重視するスタートアップ、月額サブスクリプションモデルを展開するSaaS企業、マーケットプレイスやプラットフォーム事業を展開する企業、将来的なグローバル展開を視野に入れているプロジェクトに強く推奨される。
* **選択時のポイント**:
  導入の初期費用や月額固定費がゼロであり、アカウント登録から数分で実装を開始できる手軽さが最大の魅力である。一方で、「日本の高齢者層もターゲットにしており、マイナーなコンビニ決済や独自のキャリア決済まですべて網羅したい」「手厚い電話サポートが必須である」といったドメスティックな要件が非常に強い場合は、GMOペイメントゲートウェイなどの国内専業プレイヤーと比較検討する必要がある。
